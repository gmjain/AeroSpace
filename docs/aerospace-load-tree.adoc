== Description

// tag::body[]
{manpurpose}

Reads JSON produced by xref:dump-tree.adoc[aerospace-dump-tree] from stdin and
reconstructs each workspace: workspace-to-monitor assignment, the tiling tree
(pulling windows from other workspaces when needed), the visible workspace per
monitor, and the focused window. Windows mentioned in the dump that no longer
exist are skipped; live windows not mentioned are force-retiled onto their
workspace.

Example: `aerospace dump-tree > tree.json; ...; aerospace load-tree < tree.json`
