// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

Prints a JSON document describing every workspace: its monitor, visibility,
focus, the full tiling tree (containers with orientation, layout and weights;
windows with ids), and floating windows. The output is accepted by
xref:load-tree.adoc[aerospace-load-tree] and is written automatically by
xref:restart.adoc[aerospace-restart].
